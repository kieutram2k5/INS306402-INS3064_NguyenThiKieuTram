# Requirements List

1. The system must allow students to create a new service request.
2. Each request must include a title, description, location, and request category.
3. The system must automatically assign a default status of “Pending” when a new request is submitted.
4. Students must be able to view a list of all requests they have submitted.
5. Students must be able to view detailed information of a specific request.
6. Staff members must be able to view all submitted requests.
7. Staff members must be able to update the status of a request.
8. The system must support three request statuses: Pending, In Progress, and Done.
9. The system must store the date and time when a request is created.
10. The system must record which student submitted the request.
11. The system must allow staff to add internal notes when processing a request.
12. The system should validate that required fields are not empty before saving a request.
13. The system should provide a simple and clear user interface for both students and staff.
14. The system should separate responsibilities clearly between data handling, business logic, and presentation.
15. The system should follow MVC structure to make future development easier.
